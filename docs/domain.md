1. FLO의 판매 이용권

* FLO의 기준 상품은 정규 판매상품의 기본 정보 규격이다. 기준 상품을 활용하여 정규 판매상품 및 그 외 판매상품을 추가 생성할 수 있다. 

\*기준 상품에 매핑 되는 티켓은 정규 상품의 정보 정산 대상 금액 정보를 담고 있다.  
\*기준 상품 종류는 아래 1.1 기준 상품 정의 참고 

* FLO의 판매상품은 실제 고객이 구매·사용할 수 있으며 각 판매상품 별 고유 ID가 생성된다. 

1개의 기준 상품 당 생성되는 판매상품 개수는 제한이 없다.   
\*판매상품의 고유 ID 규칙은 최종 정의 후 반영 예정

* FLO의 판매상품 사용 유효기간은 결제일로부터 기본 1개월의 월 단위를 적용된다. 

\*단권 상품의 경우 판매상품의 사용 시작일 00시로 맞추며 사용 종료는 23:59:59초로 1회차는 최대+1일 보너스로 제공된다.  
\*정기결제 상품의 경우 판매상품의 사용 시작은 결제 시간 관계없이 00시에 맞추며, 종료는 23:59:59초에 맞춘다. (1회차는 최대+1일 보너스제공) 매월 동일한 날짜에 사용 시작이 되며 단, 사용 시작이 되는 월에 해당 일자가 없을 경우 해당 월의 말일에 맞춰 사용 시작된다. (ex. 1월 31일 첫 결제 진행 2월 28일까지 사용 가능, 다음 회차 결제는 2월 28일 진행하여 3월 1일부터 3월 31일까지 사용 가능)  
\* 정기결제 실패로 재결제 또는 재배치가 될 경우 최대+1일 보너스 없이 사용 시작은 00시에 맞춘다.  
\*별도의 해당 월, 고정기간(일)의 사용 유효기간 적용이 필요 할 경우 레이블 파트너쉽팀/플랫폼사업팀과 별도 협의

* 각 기준 상품은 아래와 같은 속성을 가진다. (ADMIN에서 직접 등록)

| 기준 상품 ID | 자동 생성 또는 직접 입력 | 판매 채널 | 일반·WEB/AOS/iOS |
| :---: | :---: | :---: | :---: |
| **기준 상품 명** | 직접 입력 | **판매 가격** | 판매상품의 정상가 |
| **정산 타입** | 모바일/올인원 | **기준 사용 기간** | 월 단위/고정 기간(일) |
| **이용 형태** | 종량제/무제한/캐시드/~~DRM/A\&F~~ | **유효 기간** | 기준 상품 정보의 유효기간 |

* 기준 상품의 티켓은 정규 판매상품의 가격을 기준으로 한다. 

* 정산 타입은 기준 상품의 음원료 정산 유형 및 사용 가능 기기를 의미한다.  
* 올인원: 모바일 및 PC, NUGU 등 모든 채널에서 이용할 수 있는 상품   
* 모바일: 모바일 기기에서만 사용할 수 있는 상품 

* 이용 형태는 아래와 같이 정의된다. 이용형태 중 캐시드/DRM/A\&F 전용은 선택 항목이다.  
* 종량제: 1분 이상 청취 시 1회 차감이 되는 상품으로 정해진 횟수만큼 청취 가능 (1개월권만 판매)  
* 무제한: 횟수 제한 없이 판매상품의 사용 기간 동안 무제한으로 청취 가능   
* 캐시드: 횟수 제한 없이 무제한으로 청취 가능한 상품과 음원 캐시를 사용 기기 1대에 저장하여 오프라인에서 재생할 수 있게끔 하는 상품이 결합

* (패밀리 이용권 출시 시점에 적용) 청취제한은 그룹 이용권을 사용하는 인원과 장치 개수를 제한 할 수 있다. 

* 기준 상품의 판매 채널은 아래와 같이 정의된다.   
  * 일반▪WEB: PC/M-WEB 용  
  * AOS 일반, AOS : 안드로이드 APP 내 일반 상품용, 안드로이드 APP 내 인 앱 상품용  
  * iOS: 애플 APP 내 인 앱 상품용

* 기준 상품의 판매 가격은 판매상품의 할인액이 반영되지 않은 정상 결제 금액 및 음원료 정산을 위한 정산 대상 금액을 의미한다.  
  * 징수규정 개정 등에 의해 판매 가격 변경 시, 기준 상품은 신규로 생성이 필요하다.

* 기준 사용 기간은 판매 상품 생성 시 사용 될 판매상품의 사용기간 유형을 의미한다.

* 기준 상품의 유효 기간은 기준 상품의 정보를 상용 서비스에서 활용할 수 있는 기간을 의미한다.

1. 판매상품 구매 정책   
* 유료 판매상품 보유 시, 보유한 판매상품의 정상가보다 실 결제가가 낮은 금액의 판매상품은 구매가 불가능하다. 보유한 판매상품의 정상가보다 실 결제가가 높은 금액의 판매상품 구매 시 즉시 변경 구매 정책에 따른다. (구글 인앱 결제 상품은 즉시 변경 불가, 해지 후 재구매 가능)

* 모든 판매상품은 최소 결제가 100원 (VAT 제외)이 결제되어야 한다.

\* 무료 결제가 필요할 경우 플랫폼사업팀/이용권 개발팀과 논의 필요

* 판매상품에 적용되는 T멤버십 혜택은 연내 최대 6회 30% 할인 또는 적립이 가능하며, 할인 금액이 적용 된 잔여 금액의 최대 100%까지 보유 포인트 사용이 가능하다. (구글 인앱 결제는 적용 불가)  
* 연도 변경 시 할인 가능한 횟수는 초기화 되며 판매상품의 할인 적용은 자동 적용되지 않음   
* 이용권→MY에서 정기결제 판매상품에 한해 T멤버십 수동 할인 적용 가능  
* 정기결제 진행 중 T멤버십 할인 횟수 한도 부족 또는 사용 가능한 보유 포인트가 없을 경우 정상가로 결제 진행, 혜택 횟수 카운트는 PG사 최종 결제 승인 후 차감 적용   
* T멤버십 할인/적립/포인트 사용 판매상품을 구매한 고객이 청약철회 시 차감 된 횟수 원복

* 판매상품의 단권 구매/정기결제 시작/정기결제 해지 예약/해지 예약 취소/해지 완료 시점에 고객에게 LMS 및 메일을 통해 알림이 발송된다. 

* 판매상품의 결제가가 도래하는 회차에 무료 → 유료 전환 또는 가격 상승이 있을 경우 결제 안내 알림톡이 정기결제 배치일 D-7일에 발송된다. 단, T플러스 포인트 사용에 따른 결제가 변동에 대한 알림톡은 발송되지 않는다. 

* 정기 결제 수단은 각 POC 별 아래의 경로에서 변경 가능하며 다음 결제 회차부터 변경 적용된다.  
* \[APP\] 접속 → 이용권 → MY → 결제 수단 관리  
* \[WEB\] 접속 → 이용권 → MY → 결제 수단 관리

* 정기결제 판매상품의 자동결제가 한도초과/잔액부족/승인거절 등의 이슈로 실패했을 경우 재 결제 정책은 아래와 같다.  
  * 유예기간 10일 내 (구글 인앱 결제는 30일 내) 고객에게 발송된 MMS 내 재 결제 링크 또는 APP 내 결제 수단 관리를 통해 재 결제  
  * 유예기간 10일 내 (구글 인앱 결제는 30일 내) 결제실패 상품 보유 고객 대상으로 신규 판매상품 구매 시도 시 재 결제 안내 메시지 노출 → 재 결제 없이 신규 유료 상품 구매 시, 유예기간 종료 처리    
  * 유예시간 10일 경과 시 (구글 인앱 결제는 30일 경과 시) , 정기결제 상품은 자동 해지 완료

* 이용권 상품 구매는 FLO ID회원만 가능하다.  
* 기존 MDN 회원이 유료 결제 시도시, ID 회원 전환 프로세스를 진행해야 한다.  
* 명시된 예외 상품 (FLO & Data, FLO & Data Plus, 우주패스 FLO 이용권)은 MDN은 ID 회원 전환 없이 구매가 가능하다.

1. 쿠폰 상품 등록 정책   
* 쿠폰의 난수 번호는 숫자 16자리로 구성된다. 

\* 난수 번호의 맨 앞자리는 0을 사용하지 않고 1\~9를 사용한다.  
\* 프로모션 쿠폰의 경우 구분 값을 위해 앞 6자리를 프로모션 번호로 대체한다.

* 쿠폰 난수 번호는 ADMIN에서 발급이 가능하며, 정기결제 상품 쿠폰 발행이 가능하다. 

\* 정기결제 상품 쿠폰: 쿠폰 등록 시, 상세 결제 페이지를 통해 결제수단 등록-정기 결제가 진행되는 쿠폰 

* 쿠폰은 1개의 난수 번호로 1개의 계정에만 등록할 수 있는 1:1 등록을 기본으로 한다. 

\* 사전 협의에 따라 1: N 쿠폰 발행도 가능하다 특수 케이스에만 허용한다. 

* 쿠폰 생성 시 사전 정산 (등록 여부 관계없음), 후 정산 (등록 건수 기준) 여부 운영이 필요하다.

* 모든 쿠폰 등록 시 접속 계정이 판매상품을 보유하고 있을 경우 쿠폰 함에 “사용전환” 상태로 등록

\* 보유하고 있는 판매상품의 유/무료 여부 관계없이 쿠폰 등록을 통한 판매상품 이중 보유 불가 정책

* Bulk로 거래된 B2B 쿠폰 상품의 경우 사용/미 사용 쿠폰 확인 후 사용되지 않는 쿠폰 상품에 대한 폐기처리 진행이 필요하다. 

* 무제한 듣기+오프라인 재생 판매상품은 유료 속성의 쿠폰 생성만 가능하다. 

* AOS/iOS 인앱 상품은 쿠폰으로 생성 할 수 없다. 

* 쿠폰 난수 번호 등록 시, 제휴처의 이용권 보유 정보 체크 등의 별도 로직 적용이 필요할 경우 플랫폼사업팀과 이용권&정산 개발팀과의 사전 협의가 필요하다.

1. 판매상품 청약 철회 및 환불 정책

     \* 청약철회 기간은 1회차 결제일 익일 0시부터 계산하며, 2회차 이후부터는 이용권 사용 시작일을 기준으로 함

  \* AOS 인앱 상품의 경우 플레이 콘솔을 통해 일할 환불이 불가능하여, 고객센터를 통해 계좌 환불 처리한다.

  * 즉시변경 된 판매상품의 해지 및 환불 기준은 변경된 판매상품만 대상
